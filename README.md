# Python Standard Library Map

A practical map of the Python Standard Library.

The official Python documentation tells you **how modules work**.

This repository helps you understand **why modules exist** and **what problems they solve**.

The goal of this repository is simple:

> _**Show what each Python Standard Library module is actually used for** (see the below Module Map)_.

---

## Module Map

This module map maps 1:1 (one-to-one) with the table of contents from [`The Python Standard Library reference manual`](https://docs.python.org/3/library/index.html).

---
